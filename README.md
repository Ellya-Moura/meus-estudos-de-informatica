# 🚀 Meus Estudos de Informática do Zero

Este é o meu caderno virtual oficial. Vou usar este repositório no GitHub para registrar toda a minha evolução na tecnologia, começando do absoluto zero.

---

## 📂 CRONOGRAMA DE APRENDIZADO

### 💻 Módulo 1: Entendendo o Computador (Hardware)
- [ ] **Processador (CPU):** O cérebro do computador e como ele executa tarefas.
- [ ] **Memória RAM:** O que é a memória de curto prazo e por que ela limpa ao desligar.
- [ ] **Armazenamento (HD vs SSD):** Onde ficam guardados os arquivos e qual a diferença de velocidade.
- [ ] **Placa-Mãe e Periféricos:** Como as peças se conectam (mouse, teclado, monitor).

### ⚙️ Módulo 2: Sistemas Operacionais e Programas (Software)
- [ ] **Sistemas Operacionais:** Entender as diferenças entre Windows, Android, iOS e Linux.
- [ ] **Arquivos e Pastas:** Como organizar o computador por dentro, extensões de arquivos (.txt, .jpg, .pdf).
- [ ] **Navegadores e Internet:** Como o navegador (Chrome, Edge, Safari) se conecta aos sites.
- [ ] **A Nuvem:** O que significa salvar coisas na internet (Google Drive, OneDrive).

### 🧠 Módulo 3: Lógica e o Pensamento de Programador
- [ ] **O que é um Algoritmo:** Como criar uma sequência de passos lógicos para resolver um problema.
- [ ] **Variáveis:** Como o computador guarda uma informação na memória enquanto roda um programa.
- [ ] **Condicionais (Se / Senão):** Ensinar o computador a tomar decisões simples.

### 🌐 Módulo 4: Primeiros Passos no Mundo Dev
- [ ] **HTML5:** Aprender a criar a estrutura básica de uma página de internet.
- [ ] **CSS3:** Aprender a colocar cores, mudar fontes e estilizar uma página.
- [ ] **Git e GitHub:** Dominar o uso básico desta ferramenta que estou usando agora.
